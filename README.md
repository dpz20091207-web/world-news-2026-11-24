A hand-drawn 1024x1024 front page summing up Tuesday 24 November 2026: Wall Street's best day since April 2025 as the hero story, with a rising chart and a computer chip, plus 14 more verified stories across 7 regions, each with its own drawn pictogram. The program draws the whole image from scratch with a hand-written PNG encoder (Node 22 standard library only, no network, no external assets) and writes it deterministically to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
